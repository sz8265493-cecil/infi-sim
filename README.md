# infi-sim

Infinity N5 的非官方二维战术沙盘，用于非盈利的规则测试、教学和游戏推广。支持单浏览器中双方手动操作；不是官方 Army 的替代品，也不是已完整实现全部规则的线上对战服务。

> **当前状态（2026-10-27）**：本地开发与网页实操验证，GitHub 私有仓库存储源码，Actions 自动测试。**不启用 GitHub Pages，也不向 GPT Sites 发布更新。** 历史部署文档不代表当前工作流。
>
> 规则争议以最新官方规则、FAQ 和赛事裁定为准。已实现基本行动，不代表所有交叉组合均通过验证；具体证据见[覆盖矩阵](docs/rules/EXAMPLE_EXECUTION_MATRIX.md)。

## 快速开始

需要 Python 3（静态服务器）；Node.js 22+ 和 npm 用于测试与启动脚本。没有运行时 npm 依赖，不需要构建或执行 npm install。

```bash
git clone https://github.com/sz8265493-cecil/infi-sim.git
cd infi-sim
npm start
# 打开 http://localhost:4173/
```

私有仓库需要有权限的 GitHub 账号认证。不要直接双击 HTML：ES Modules 和 JSON 需要 HTTP 服务。

也可以只用 Python 启动仅本机可访问的预览：

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

停止服务器：在启动它的终端按 Ctrl+C。端口占用时，可改用其他端口，但不同端口不会共享浏览器存档。

## 如何使用

- **真实比赛**：选择已支持的 ITS 任务 → 导入双方官方 Army 军表代码 → 先攻/部署权检定 → 主体与保留模型部署 → 合法火力组配置 → 完成开局步骤后开始游戏。战斗组分别管理命令池。
- **教学演示**：从目录搜索规则或场景，按提示宣告并结算。默认随机掷骰；手动勾选“固定教学骰例”后使用预设序列，便于复现。相同骰点不一定表示故障；固定例本来就会重复。
- **多目标分枪**：主动射击时分配各目标的 B 和 SD，各反应者独立宣告；分别计算修正、拼骰、命中、过保、伤害和后续移动。对一个目标的成功不能抵消另一个目标的攻击骰。
- **存档**：比赛和教学分别保存在当前浏览器的 localStorage。刷新可以继续；换浏览器、域名或端口不会自动迁移。没有账号、云存档、联网对战或双方私密信息隔离。

## 当前能力与明确限制

| 范围 | 当前情况 |
|---|---|
| 比赛与军表 | 支持玉京及军事修会目录、官方军表代码、Hardlock/Annihilation、先攻与部署、手动火力组、命令池。导入严格匹配单位/组/选项编号，不拿其他配置替换未知条目。 |
| 宣告与结算 | 主动轮和 ARO 条件、分枪、SD 弃骰、独立过保动画、伤害/状态、闪避及勇气移动。 |
| 技能与联动 | 医生/工程师、医疗包/维修包、黑客、协调命令、火力组、部署物、部分附属模型/变形/生存与连锁规则；具体组合按覆盖矩阵核验。 |
| 地形与区域 | 高度、楼板开口、桥下、烟雾/Eclipse、能见度/饱和/困难区域。任意曲面、异形地形和部分跨层模板仍采用几何近似。 |
| 配置缺口 | 多形态完整数据、混合多附属导入尚未补齐。匹配不到或无法安全展开的配置拒绝导入；可识别但部分能力未实现的配置会逐项提示并要求确认，只用于支持范围内的教学。 |
| 比赛完整性 | 不保证所有 ITS 任务、机密任务、Retreat、三回合与特殊结束条件完全覆盖。 |

本轮仍待验证：普通枪击与多治疗者同令、自疗攻击点；显式多模板与饱和；部分协调特殊程序；隐匿突袭和整组显形失败边界；更长对局的恢复流程。不要把自动测试通过解读为全部官方规则完成。

## 工程目录

- `dist/`：网页与可编辑 ES Modules 源码、图片、军表数据；无打包步骤。
- `tests/`：Node 内置测试框架的规则/几何回归。
- `scripts/`：官方 Army 数据整理脚本。
- `docs/rules/`：规则来源、学习记录、网页实操证据与覆盖矩阵。
- `artifacts/`：本地网页验收截图，不含玩家浏览器存档。
- `.github/workflows/test.yml`：push/PR/手动触发的自动测试，只读权限。
- `MIGRATION.md`：独立托管和存档迁移；其中旧部署方案仅作历史记录。
- `RULES_V8.md`、`README_HISTORY.md`：历史实现说明，当前覆盖范围以最新矩阵为准。
- `.openai/hosting.json`：旧站点关联信息，不用于当前部署，也不是认证密钥。

# 第78轮：中继网络与防火墙（仅本地）

官方：[Repeater](https://infinitythewiki.com/Repeater)、[Firewall](https://infinitythewiki.com/Firewall)，2026-10-23核对N5.3/FAQ v0.1。

声明界面可选自身、友方网络/指定中继器、敌方中继器；选项不预量。敌方路径限本人位于其ZoC时攻击对方黑客。多防火墙由受益者选择，负修正不叠加，过保始终只有+3。设备防火墙在孤立/空状态失效。共生通讯攻击也应用防火墙。

网页实际操作：

- `enemyRepeater78`：红12/28，蓝36/20，隔9寸墙；敌方中继器14/28。蓝方Reset，主动Spotlight指定敌方中继器。结算页可选设备−6或网络−3；改选−3后SV7→10。B2骰8/9对Reset20；2次AP BTS过保SV10，骰20/1，0伤并Targeted。完成勇气及命令。
- `enemyRepeaterARO78`：红方中继器靠近远处蓝黑客，蓝方无LoF也通过敌方中继路径获得ARO。蓝Spotlight B1 SV10骰8，红Reset SV13骰20；1次AP BTS过保SV8（含Firewall+3），20失败，Targeted。完成勇气及命令。

回归涵盖远端非黑客不可作为敌方网络目标、自身路径够不到远端目标、各防火墙只选一个。未重跑所有支援程序先后顺序；该项仍留在覆盖矩阵。

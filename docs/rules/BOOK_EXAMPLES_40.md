# 规则书其他示例：第二轮网页验收

日期：2026-10-22。依据用户提供N5规则书V5.3的印刷p78、p165。延续上一轮要求：仅本地开发和实际网页操作，未同步GitHub。

## p78 Discover + BS Attack

新增auditDiscoverFail78和auditDiscoverRemote78配置，使用通用发现/射击/ARO/过保引擎。

- 单目标失败分支：主动发现SV13掷20失败；已宣告的射击转为待机，主动攻击骰0，无过保，目标仍迷彩。同一观察者本回合再次开始发现同一标记被阻止，未再扣命令。
- 组合分支：迷彩放弃ARO，另一遥控机宣告复合步枪ARO。发现20失败后只取消主动射击，遥控机仍独立掷8/SV14命中。主动方ARM1+PS7=SV8，过保20失败进入昏迷；迷彩目标仍camouflaged，遥控机正常。
- 实测发现并修复交叉错误：Alert的攻击快照此前在发现检定之前生成，导致发现失败、射击转Idle后，迷彩目标仍错误获得Alert。现改为在前置技能检定结束、进入攻击结算时才保存快照。重跑单目标和遥控机组合：没有这次无效主动射击导致的错误Alert。
- 证据：/Users/bytedance/Documents/tt/infi-discover-failure-fixed.png、infi-discover-remote78.png。

这验证失败/有效敌ARO保留分支；多目标分枪中发现一个标记失败只取消该组B等扩展仍未实测，不将其标为全部p78图例通过。

## p165 IMM-A：受限反应与成功/失败分支

新增auditImmA165和auditImmA165Success。以低墙模拟部分掩体，轻机枪B4，BS13+射程3−掩体3=SV13，对方PH10−6=SV4。

1. 失败分支：ARO菜单没有射击/Look Out；Reset的option明确disabled，Dodge可选。主动掷5/9/12/14，反应掷20：三发命中、三次过保，14失败。ARM1+PS6+掩体3=SV10，三颗20均失败，目标承受3伤移除，完整结算到战报。
2. 成功分支：主动掷2/3/20/20，反应掷4为暴击。无未抵消命中，不进入过保；先解除IMM-A，然后开放正常闪避移动。实际地图点击并确认1.46寸，从(20,19.51)移动至约(20,18.05)，正常状态，站立、朝向90度；未消耗额外命令，未产生新ARO。
3. 证据：/Users/bytedance/Documents/tt/infi-immA-three-hits.png。

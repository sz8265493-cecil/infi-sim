# 第71轮：直觉攻击与伤害型推测射击

2026-10-23，仅本地。依据官方 [Intuitive Attack](https://infinitythewiki.com/Intuitive_Attack)、[Speculative Attack](https://infinitythewiki.com/Speculative_Attack) 的 N5.3 页面与官方武器属性。

这两项现在是首项整令入口，不能作为第二短技能或 ARO。只有武器具有对应属性才出现；导入武器保留各自弹药、伤害和持续伤害。直觉攻击用无修正 WIP、B1，不应用额外B/SD；失败记录针对目标与主动回合。推测攻击用原武器的射击属性、−6与距离修正，可偏移圆模板爆心，要求覆盖主目标。宣告前不显示模板或测距。

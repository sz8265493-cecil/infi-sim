# 第98轮：全息公开时点与隐匿部署组合（2026-10-25，仅本地）

核对官方 [Holoecho State](https://infinitythewiki.com/Holoecho_State)、[HoloMask State](https://infinitythewiki.com/HoloMask_State)、[Hidden Deployment](https://infinitythewiki.com/Hidden_Deployment_State)。Wiki 当前提示 N5.3 / FAQ v0.1。模型外观组合的公开时点按 Effects 的“首次主动激活”执行；页面底部例文简写“主动回合开始”，此处采用完整效果条款。

## 已修复

- HoloMask + Holoecho 组合初始不显示全息标记；首次主动激活选择三体中任一模型旁放一枚公开标记，之后不随下一次命令挪回真身。
- 宣告攻击即时取消规则状态，但地图模型外观保留至命令结束；结束再换回真模型并移除假体。
- 隐匿部署生成回声时保留三者隐藏状态，记录完整位置；激活或反应揭露真身时三者同时显现并检查一致性。
- 隐匿单位可使用自身保留命令，不向公共池供令、不消耗公共池，使用后不再提供此来源。

## 真实 Chrome 网页操作

| 场景 | 实际结果 |
| --- | --- |
| holoPublicIdle98 | 初始三体均无公开状态图标；选模型乙(28,28)，开始后仅该处一枚标记；敌延后、主动Idle，延后自动失效，无骰结束，三体保留。刷新后再走一令，标记仍在模型乙，没有回到真身。 |
| holoPublic98 | 标记选模型甲，敌选择该假体延后；真身射击后反应目标只有真身。攻击8/9/20对6，两次命中、两次ARM保1/1通过；勇敢坚守后假体移除，地图文字从IMITATED SNIPER换回REAL BEARER。 |
| holoHidden98 | 初始地图只有蓝方模型；选隐匿保留命令，Idle后红方三体一起出现；延后→Idle→失效完整结束；公共命令保持3，自身保留来源消失。 |
| holoHiddenBroken98 | 真身与其余两体不一致，开始命令后、测量移动前立即移除两个假体；Idle+Idle完整结束。 |
| holoHiddenARO98 | 结束红回合，蓝Idle，隐匿真身射击ARO使全部三体出现；蓝Idle，反应骰8一命中，保1成功，勇敢坚守后假体移除。 |
| holoHiddenDeploy98 | 部署选隐匿，再点(24,40)/(28,40)放两回声；地图仅蓝方模型。完成双方主要/保留部署，跳过双方Speedball后开始第一轮；红方公共池0，可选自身保留命令。 |

上述场景由页面按钮、下拉框和地图点击执行，不通过浏览器脚本直接改游戏状态。固定教学骰仅在教学场景手动开启。

## 边界

共享屏幕仍显示拥有者的真实配置，不是双方账户隐私系统。隐匿位置被其他模型占据时的最近合法替代位置、全部朝向/状态/Sensor组合仍需另验，不据此宣称整个隐匿部署规则穷举完成。新增5项回归与既有测试共同通过；详见本轮最终测试记录。

# 第112轮：同目标技术恢复与修伤

日期：2026-10-27。N5.3 / FAQ v0.1，仅本地。

## 依据与解释边界

[Tech-Recovery](https://infinitythewiki.com/Tech-Recovery)允许友方GizmoKit命中/接触后用PH清除工程师可解除的状态，但不清昏迷、不修伤，失败无额外伤害；Null状态仍有效。[Stunned](https://infinitythewiki.com/Stunned_State)对非过保检定−3，故接受者PH也受影响。

官方技术恢复示例是分两条命令清状态/修伤。本轮两名联动模型同令使用不同恢复目的，是按装备条文和同时结算规则组合推导，并非官方专门FAQ示例。按目的分别汇总；一组成功不能替另一组抵消失败。双方检定均冻结同令开始时目标的资格/修正；汇总时先正面效果，再负面效果。

## 实际Chrome操作

每场均Idle、ARO、控制者远程GizmoKit目标/目的、附属自身远程GizmoKit同目标/另一目的、ARO，然后逐人BS命中与接受者PH，最后统一应用。命中SV14，默认PH10。

修复：同目标所有装备恢复等待全部检定；按装备和恢复目的独立合并；避免后一结果覆盖前一目的；PH加入既有眩晕修正。原始目标快照不随动画显示顺序改变。

# 第99轮：附属模型独立攻击、双仆从与控制单元

核对及实操日期：2026-10-25。官方 [Peripheral](https://infinitythewiki.com/Peripheral) 页显示N5.3及FAQ v0.1。仅本地修改和Chrome网页实际操作，未提交或推送GitHub。

## 改动

- 同步、Ancillary等联动攻击按各模型自己的武器、完整B、目标和修正建独立骰池；不是协调命令，不套用先锋减半或成员B1。
- 主体分枪与附属攻击可并存；SD按主目标分配，副模型保留自身B。对同一反应者复用同一组反应骰，再按攻击者分别比较。
- 附属直射模板宣告前只给短方向提示，可以点击调整；完整盖板仅在确认宣告后显示。
- 两名Servant每次主动命令／反应窗口选择一名；另一名不激活。远程接触治疗使用控制者WIP，只有所选仆从提供接触点，Doctor/Engineer仍禁止ARO。
- Control每次主动命令可选先锋；只有控制者和先锋执行有目标攻击，其他成员待机。先锋在本次攻击伤害结算后失能，须立即选新先锋，再进入后续阶段。

## 保留边界

- Cyberplug的Connected/Autonomous双配置与独立命令／ARO尚未实现，不能用Ancillary代替。
- Control本轮覆盖有目标攻击和主伤害结算时先锋替换；非攻击目标技能、地雷/Explode后续波次中的全部即时换先锋组合仍需补齐。
- 精确多附属军表资料不完整时仍拒绝导入，教学配置不修改官方军表。
- Servant的普通Doctor救治已网页通过，技术恢复、Engineer等全部状态/多层接触组合不能由本场景推定完成。

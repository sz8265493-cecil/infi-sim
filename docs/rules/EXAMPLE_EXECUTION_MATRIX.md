## 结论与优先级

不能宣称目前具备规则书所有操作示例的完整执行能力。先修正式规则差异（完整B、信息时点、单位/地形几何），再补缺失行动（Cautious、Look Out、Alert、Speedball），随后补多模板/协同/混合联动，最后按技能和装备扩展特殊场景。每项以完整浏览器操作为验收，保留失败项，不以已有函数或自动测试数量代替。

# 第100轮：协调射击误伤

2026-10-25，仅本地。依据官方 [Ballistic Skills](https://infinitythewiki.com/Ballistic_Skills) 的射入近战条文和 [Coordinated Orders](https://infinitythewiki.com/Coordinated_Orders) 的B与共同目标规则。新增可选教学场景friendlyCoord100，复用现有通用误伤结算，不写场景专用判定。

真实Chrome操作：手动勾选本人和第二射手，开始协调命令，Idle→敌方放弃ARO→两人Combi射同一近战目标。两名交战友军使射击修正−12，最终两射手SV5。先锋B2骰3/8，成员B1骰20。

点击比较后分别为两颗失败骰选择误伤承受者：8给友军甲，20给友军乙。过保页面出现三份独立计划：敌方1命中，甲1误伤，乙1误伤，三者各ARM1+PS7=SV8；掷1/1/1均成功。确认伤害后直接返回命令选择，无不必要勇气/过保界面。战报保留每颗误伤骰与承受者；命令池3→2，宣告日志明确1正规+1指挥令。

本轮不表示协调命令所有特殊弹药、SD、模板或整令组合已经人工穷举。未同步GitHub。

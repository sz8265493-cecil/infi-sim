# 第105轮：多重生存选择、先锋与连锁（2026-10-25，仅本地）

依据官方当前 N5.3 / FAQ v0.1：[NWI](https://infinitythewiki.com/No_Wound_Incapacitation)、[Dogged](https://infinitythewiki.com/Dogged)、[Explode](https://infinitythewiki.com/Explode)、[Peripheral](https://infinitythewiki.com/Peripheral)、[Dodge](https://infinitythewiki.com/Dodge)。

## 修复

此前主伤害或后续自爆造成先锋昏迷时，会先要求换先锋，再让模型选择NWI/顽强；这与生存技能忽略Null标签的效果冲突。现在先逐一确认同波生存选择，界面显示剩余人数，再按最终状态判断先锋、闪避移动、自爆和勇气。火力组同步也推迟到最终状态确定后，避免尚未决定是否启用NWI时提前脱组。

NWI/顽强抑制自身Explode；放弃选择则保留昏迷和自爆资格。后续波次若产生新生存选择，会重新进入同一流程。已有NWI再次受伤直接移除，不追加生存选择或自爆。成功闪避的模型不在应用伤害时提前从移动队列删除，而在生存选择结束后以最终状态筛选。

上述阶段排序是依据这些规则共同效果的整合，不声称官方存在专门描述所有这些组合的FAQ。

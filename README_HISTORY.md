# infi-sim · Yu Jing Tactical Lab v0.8

48×48 英寸二维 Infinity 教学沙盘；纯 HTML/CSS/ES Modules，无运行时第三方依赖。

## 运行

`npm start` 后访问 http://localhost:4173；`npm test` 运行规则与几何测试。

## 操作

选择主动单位和第一技能 → 规划移动、跳跃或攀爬／待机 → 敌方 ARO → 第二技能（Move、射击、近战、Dodge、Reset 或 Idle） → 新增 ARO → 掷骰动画 → 弃骰与比较 → 命中／过保次数 → 独立过保动画 → 确认伤害与状态 → 可选闪避移动。普通 Jump／Climb 占整令，没有第二技能。

部署时可选择 0/4/6/9 英寸水平面，再点己方部署区的屋顶。楼房颜色区分高度；单位显示脚底 Z 与轮廓高。地图下方“高度与视线剖面”可选择观察对象。

新增教学场景：地面与屋顶视线、普通攀爬上楼、超级跳、火力组额外骰与弃骰、无限高围墙任务房间。保留近战、闪避、俯卧、结算时选择目标位置。固定教学骰公开显示，可以关闭。

“命令表 / 火力组”列出 N5.3 常见技能及实现状态，并链接官方完整速查表。单位属性的火力组奖励实验允许重现 L2 SD、L3 Dodge、L4 BS，不建立完整火力组。双方掷完后主动方先弃骰，再由反应方弃骰。每次结果含原始点数、失败/抵消/暴击、过保骰与伤害，最近 12 条可回看；刷新不会重掷待比较骰子。

## 实现与边界

- 48×48 英寸、1 英寸网格；底座保持毫米实尺。S2/S3/S4/S6/S7 高度依次 40/32/32/55/67 mm；俯卧为 3 mm。
- 有限高度盒体与圆柱轮廓三维射线采样，近似检查 3×3 mm 可见区域。侧面图画中心切面，几何判断采样其他轮廓点。未精确模拟模型遮挡、女儿墙、异形建筑和旋转墙面底座。
- 地面/楼顶部署、两段 Move 分别使用 MOV1/MOV2，低障碍翻越、普通 Climb/Jump、首项 Climbing Plus/Super-Jump。攀爬墙面路径是圆柱近似；强化攀爬可使用面板规划 Move/Dodge 沿墙；梯子、Jet Propulsion 任意转向未实现。普通 Climb 悬挂时仅能继续爬，不能 ARO。
- 墙角保留完整圆形底座扫掠；成对平行墙窄道采用半宽近似，完整终点。不能把所有墙角当无半径路径。
- Jump 使用三维抛物线路径，检查全底座水平落点、距离和建筑碰撞。界面选择“额外抬升”控制曲线。Climb MOV1+2，超级跳短 MOV1+2、长 MOV1+4。
- ARO 检查全路径 LoF/ZoC；射击、近战、闪避、普通 Reset。Reset 不抵消普通射击；已实现 IMM-A/IMM-B/孤立/眩晕/被锁定修正与解除；尚无黑客程序。Discover、谨慎移动等仅提供规则索引，明确未实现。
- 武器绑定大小泪滴/圆形模板；跨层倾斜模板和模板 ARO 未实现。基础同时结算、暴击、EXP/AP/连续伤害。超过 20 的成功值、完整特殊技能、AI/联机未实现。
- 火力组仅奖励与骰例实验，没有合法编组、一致性、整组激活及第六感逻辑。普通概率仅无 SD 的 B 对 B1，复杂情况不显示误导性概率。
- 无限高房间只在专门教学场景启用：中空围墙和四个 3 英寸入口，门宽是教学参数，不是某一 ITS 任务的精确复刻。默认任务仍为 Battleground。
- 单位属性、费用和额外训练装备不能作为合法编军依据。所有近似在页面“规则与边界”中展示。

- 医生/工程师/特殊复活、勇气检定等尚未实现。状态训练开关只是布置场景，不是治疗。
- 矮墙高度0.7″（低于S1）与1.7″（略高于S2）在地图标注。接触且部分遮挡给掩体，无三分之一阈值。加入4个教学场景：DA过保、E/M状态、PARA状态、矮墙。
